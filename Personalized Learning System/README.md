# Personalized Learning Recommendation System (KNN)

This project is a simple web-based demo of a Personalized Learning Recommendation System using the K-Nearest Neighbors (KNN) algorithm with a larger synthetic dataset.

## Quick Start

1. Create a virtual environment and install dependencies:
   ```
   python -m venv venv
   venv\Scripts\activate   # On Windows
   pip install -r requirements.txt
   ```

2. Train the model:
   ```
   py train_model.py
   ```

3. Run the web app:
   ```
   py app.py
   ```
   Open http://127.0.0.1:5000 in your browser.
